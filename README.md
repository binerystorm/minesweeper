# Description
This is an implementation of minesweeper in C++. I started this project to learn C++ and to see how it differed from C, it is therefore, not very "pretty".

# Dependencies
This project is made using raylib.

# Usage
To compile the program, make sure you are in the projects root directory (not `src/`), and execute the following in a terminal:
```
$ chmod +x ./build.sh
$ ./build.sh
```
To run the program, simply execute:
```
$ ./main
```
Should you want to change some of the games parameters (e.g. the board size, the amount of bombs, etc.), This can be done by changing the desired parameter in `src/settings.hpp` and then recompiling the program.
